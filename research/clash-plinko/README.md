## Mathematical checks once the tables are available

For slot probabilities p[i] and gross payout multipliers m[i]:

    sum(p[i]) = 1
    RTP = sum(p[i] * m[i])
    house_edge = 1 - RTP
    probability_of_profit = sum(p[i] where m[i] > 1)

If payouts are capped, replace each multiplier with min(stake*m[i], cap)/stake. Verify the actual rounding rules separately. A symmetric binomial distribution may only be used if the documented RNG mapping supports independent 50/50 steps; it is not established here.

## How to complete the collection from an accessible browser

1. Open the game and DevTools Network, preserve the log, then reload without placing a bet.
2. Save public HTML and script responses; identify Plinko chunks through the asset manifest/imports and searches for plinko, risk, multiplier, payout, probability, seed and nonce.
3. Inspect all risk modes and record their displayed slot multipliers and probability tooltips.
4. Open the Plinko section of Fairness and save the public verification explanation/code and any linked verifier.
5. Inspect read-only configuration/history traffic and public historical-result details. Avoid creating a wager to collect traffic.
6. Export a sanitized HAR that excludes cookies, authorization headers, tokens, account data and unrelated requests.
7. For each artifact, record its source URL, timestamp and SHA-256 hash. Recompute odds/RTP from the actual collected tables before drawing conclusions.

The private backend source and unrevealed server seeds cannot be collected from the public page alone.
